처음 보는 말 풀이

화면과 이 페이지에 나오는 말입니다.

chunk (청크)
PPT를 잘게 나눈 글 조각입니다. 보통 슬라이드 한 장이 chunk 하나입니다.
taxonomy (분류표)
라벨로 쓸 수 있는 항목과 값을 정해 둔 표입니다. taxonomy.xlsx 파일입니다.
축
분류표의 항목 하나입니다. 예: 층, 불량 유형, Main step. 축마다 고를 수 있는 값이 정해져 있습니다.
라벨
chunk에 붙인 축별 값입니다. 예: 층 = M1, 불량 유형 = Open.
불량 chunk
Claude가 라벨을 확신하지 못한 chunk입니다. 틀렸다는 뜻은 아니고, 사람이 확인할 대상이라는 뜻입니다.
검수
사람이 불량 chunk의 라벨을 보고 맞는지 확인하고, 틀리면 고치는 일입니다.
파싱 대조
PPT가 글로 제대로 옮겨졌는지 원본과 비교하는 일입니다. 선택 사항입니다.
임베딩
글을 숫자 목록(벡터)으로 바꾸는 일입니다. 단어가 달라도 뜻이 비슷한 글을 찾을 수 있게 됩니다.
Supabase
라벨과 벡터, 슬라이드 그림을 저장하는 데이터베이스입니다. 나중에 검색 서비스가 여기서 찾습니다.
Domain-Engr-bot
검수 기록으로 엔지니어에게 질문하고, 확정된 답을 규칙과 분류표 제안으로 바꾸는 도우미 봇입니다.
Code-Engr-bot
코드 규칙을 점검하고, 분류표의 축이 바뀐 작업을 찾아 바뀐 축만 다시 라벨링하는 도우미 봇입니다.
DRM
사내 파일 보안 장치입니다. 그래서 파일을 경로로 열지 않고, 한 번 읽어 안전한 사본(.b64)으로만 작업합니다.
