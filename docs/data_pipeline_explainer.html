한 장에 한 단계씩

각 장 아래 파란 칩은 그 단계에서 꼭 문서로 남길 것입니다(ASD-STE100 원칙).

처음 해 보는 사람에게

샘플 50개로 해 보는 7단계 실습

전체 데이터에 바로 들어가지 말고, 작은 샘플로 규칙부터 맞춰 봅니다.

  1. 샘플 데이터 50개 고르기
  2. 라벨 3~5개 정의각 라벨에 예문 1개
  3. 10개 직접 붙여 보기
  4. 같은 항목을 2명에게 맡기기일치도 확인
  5. 라벨 규칙 보완
  6. JSON·CSV로 저장
  7. Docker 예제 실행적재 스크립트 포함 이미지
오류·혼선 줄이기

시작할 때 지키면 좋은 네 가지

라벨 수

적게 시작해 점점 늘립니다

처음부터 라벨을 많이 만들면 사람마다 다르게 붙입니다. 3~5개로 시작합니다.

가이드

실제 예문을 넣습니다

"이 문장은 부정"처럼 예시가 있어야 누가 봐도 같은 라벨을 붙입니다.

자동화

자동 규칙은 보조로만

정규식·키워드 매칭은 사람 판단을 돕는 데 쓰고, 주된 판단은 사람으로 시작합니다.

버전

이미지에 태그를 붙입니다

어느 데이터와 규칙으로 만든 이미지인지 태그로 추적할 수 있게 합니다.

ASD-STE100 스타일 체크리스트

매번 남겨야 하는 다섯 가지

한 번 돌릴 때마다 다섯 개가 모두 남았는지 확인합니다. 체크 상태는 이 브라우저에만 저장됩니다.
