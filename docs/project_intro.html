    06 — TRUST

    AI가 틀리면 어떡하죠?
    그래서 세 겹으로 확인합니다

    1겹 · 검증 질문

    LLM이 자기 label에 O/X 질문을 던진다

    label마다 "정말 맞아?"를 확인하고, 근거 문장을 원문에서 그대로 인용합니다. 인용문이 원문에 없거나 확신도가 낮으면 불량 chunk의심 조각 목록에 올립니다.

    2겹 · 감시 agent

    Engr-bot과 code-bot이 따로 본다

    label을 붙인 agent와 감시하는 agent를 분리했습니다. Engr-bot은 label을 도메인 지식으로 보고 사람의 1차 검수 결과를 BEOL-labeling에 되돌려 주며(feedback loop), code-bot은 코드가 사내 규칙을 지키는지 봅니다.

    3겹 · human in the loop

    마지막 결정은 엔지니어가 한다

    사람이 고친 값이 최종 label입니다. 검수 화면의 "검수 완료"를 누르기 전에는 DB에 적재하지 않습니다.

    사내 문서는 밖으로 나가지 않습니다. 사외 개발은 더미연습용 가짜 자료로만 하고, 사내 파일은 DRM문서 보안 규칙에 따라 한 곳에서만 엽니다.
